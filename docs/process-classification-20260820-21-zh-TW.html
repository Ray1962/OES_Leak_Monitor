三群各自在測什麼

下表是每群全部檔案的平均值 ± 標準差,一律除以該檔自己的 O I 777.4 峰高。看得出三條清楚的線索。

C:Ar 稀釋的 TEOS 沉積

Ar 四條線(738 / 750 / 763 / 811)只在 C 出現,而且 CO Ångström(483.5 / 519.8 / 561 / 608)、C₂ Swan 516.5、CH 431.4 全部是三群最強 —— TEOS 的乙氧基裂解產物。與你說的 Si(OC₂H₅)₄ 完全吻合。

B:含氫、含矽的清洗

沒有 Ar,Hα/Hβ 是 A 的兩倍,Si I 251.6 / 288.2 是 A 的 1.6–2 倍,230 nm 段是 A 的四倍。這是把沉積殘留(Si–O–C–H)燒掉時該有的樣子。

A:同樣無 Ar,但碳氫比例相反

A 的 CO 三正帶(313 nm)相對 O 777 反而比 B 高(0.579 vs 0.381),H 與 Si 卻明顯較低。方向和 B 的清洗趨勢相反,所以 A 不是「比較乾淨的 B」,是另一段製程。

順帶查到的三件事

會影響 Golden Run 的觀察

視窗在一個批次內就結垢了 —— 而且是選擇性的

同一批次裡 C 步驟的絕對 O 777 峰高從約 41000 掉到 28000(× 0.70),但這不是電漿變弱:同期 Ar 750/O 777 上升 約 12 %(1.31 → 1.47),而紫外的 CO 313/O 777 卻掉到 0.61 倍。這是鍍膜對短波長吸收較強的透過率變化。長 B 跑完後下一批的 C 又回到 41000,代表清洗把視窗一起清乾淨了。任何跨越批次的 Golden Run 基線,紫外側的比值會漂到 −40 %。

波長軸整體偏高 +0.30 nm

以 Ar I 與 O I 九條原子譜線量測,實測峰位一致比文獻值高 +0.21 – +0.34 nm(bin 間距 0.354 nm)。目前 LineRegion 的 ±1 nm peak search 吃得掉,但若要在 Wavelength Calibration 分頁登記,offset 應為 −0.30 nm。

方法

怎麼算的

每個檔取全譜逐 frame 亮度,只保留亮度 ≥ 該檔最大值 60 % 的 frame 再平均,把點火斜坡與 stop-confirm 尾巴排掉。每張平均譜正規化成單位向量後兩兩取餘弦相似度,做平均連結階層分群。

k=4 時得到 72 / 74 / 75 / 5 —— 那 5 筆(08-20 19:38、19:56 與 08-21 00:36–00:39)與相鄰的 B 相似度達 0.998,是 B 在清洗末期殘留物耗盡的延續,併回 B 群。k=6 時 A 與 C 各自再裂成兩半,但那兩半只對應「批次內第幾輪」(平均序位 1.2 vs 4.5),就是上面說的視窗結垢,不是不同配方。

最後以留一法最近鄰驗證:226 筆全部的最近鄰都與自己同群,零錯誤。
