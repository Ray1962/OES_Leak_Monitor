2.1 陷阱:劑量與時間共線

閥位是按 0 → 50 → 100 → 150 → 200 的順序、依時間遞增施加的,而穿透率在同一段時間內單調下降。 任何沒有在同一波長區段內正規化的量,都會給出一條看起來很漂亮的「劑量曲線」, 而那條曲線量的是視窗,不是漏氣。

§3 的表裡可以直接看到這件事:NO 237 / CO 330 在 index 50 上升 +167.5 % 然後單調回落 —— 它的欄位形狀與 UV/NIR 那一列一模一樣。

2.2 解開:16:45 的長清洗讓兩者不再共線

清洗發生在 index 0 組之後、index 50 組之前,所以:

  • index 0 三筆的 UV/NIR 是 0.322 – 0.440(清洗前,已結垢)
  • index 200 兩筆的 UV/NIR 是 0.294 – 0.350(結垢回來了)

兩組重疊。 corr(index, log UV/NIR) = −0.248 —— 低到足以做一個兩變數迴歸, 把穿透率與閥位分開。這是這次實驗最有價值的一個意外,§4 完全建立在它上面。

4. 決定性證據:整條光譜上沒有東西隨閥門變化

§3 只看了九個事先挑好的量。如果漏氣以某種沒想到的方式呈現,上面那張表看不到。 所以把問題改成:1896 個波長裡,有沒有任何一個與閥位相關?

4.1 方法

對製程 C 的 11 筆錄檔,逐波長擬合

log( I(λ) / O777 )  =  a(λ)  +  b(λ) · log(UV/NIR)  +  c(λ) · index

b 吸收視窗穿透率,c 是漏氣會動的那一項。§2.2 的 corr = −0.248 保證這個擬合是可辨識的。 輸出按 |t(c)| 排序 —— 有反應的氮帶不可能躲起來,它會和整個二正系一起排在最上面。

4.5 為什麼 CN 388 是最關鍵的一條

計畫 §15.4 記的最大未量化風險是:含碳電漿裡漏進來的 N₂ 會有一部分變成 CN/HCN, 那會減少 N₂ 337,折損無法量化。 這是 GO 判定那 8.3 倍餘裕的唯一預算用途。

這條風險有一個直接推論:如果 N₂ 真的被 TEOS 電漿吃掉,它必須變成 CN,而 CN 388 會亮起來。 所以 N₂ 337 與 CN 388 不可能同時對漏氣無反應 —— 除非沒有氮進來。

兩者都是 −0.1 %～−0.2 %。

5. 兩種讀法,以及為什麼判「閥門沒送氣」

觀測到的事實只有一條:index 200(標稱 1.0×10⁻² mbar·L/s)相對 index 0, R_N2CO_C 動了 +1.9 %,判準是 9.3 %。

判 A,理由是 §4.3 那張表

讀法 B 要求 N₂ 337 對漏氣的響應比外推低 46 倍。就算接受這件事(§15.4 的 TEOS 折損可以吃掉一部分), 它無法解釋另外十一個特徵也同時是零:

  • N₂ 二正系的六條帶來自同一個電子態,它們不會有六種不同的折損。
  • CN 388 是折損的產物(§4.5)—— 折損越嚴重它應該越亮。
  • N₂⁺ 391.4 走的是離子化路徑,NO γ 走的是 N + O 化合路徑,都與 CN 無關。

要讓十二個化學路徑同時對 0.12 % 的空氣添加無反應,唯一的解釋是那 0.12 % 的空氣不存在。

這次測試不能回答的

GO/NO-GO 完全沒有被觸碰。 §16 的 8.3 倍餘裕既沒有被驗證也沒有被推翻, §15.4 的 TEOS 折損風險仍然是未量化的。

這與 2026-08-19 那次的失敗不同(那次是 save 門檻設在無漏電漿之上,閘門整段關著, 見 leak-test-20260819-analysis.md)—— 這次儀器、錄檔、閘門、抽取全部正常,缺的是腔體裡的氮。

6.2.1 這個比錯的量,計畫裡也有一份

計畫 §4.1 寫「A 與 B 的 mean/σ 是 7.3 與 6.5,低於引擎的 MinBaselineMeanToSigma(10) —— FinalizeCapture 會直接拒收它們的 baseline」。那張表的定義是 「取每批次第一支 step 的 10–30 s 中位數」,也就是跨批次的量; 而 MinBaselineMeanToSigma 套用的是 pooled 幀的量。

結論碰巧是對的(兩個量在 A/B 上都遠低於 10),但比較本身是錯位的, 而錯位的方向會隨製程改變:製程 C 的跨錄檔 mean/σ 是 33.7,pooled 卻只有 21.0。 用跨批次的數字去預測一次擷取會不會被收下,對 C 會高估 1.6 倍。

⚠️ 另一個警告:這一天的 B(Hα/O777 0.0555–0.0587)與 8/20–21 的 B(0.0740–0.1146) 不是同一個操作點。使用者說明這次的 B 是 3.8 torr 的 O₂ 清潔,上面的數字只對這個操作點成立。

6.4 R_N2Ar_C 否決票在這台機上不能用

計畫 §4 把它當「方向性否決票」(mean/σ 5.8)。這一天它的 index 0 基準散度是 12.0 %, 而且它的欄位形狀與 UV/NIR 完全同向(+109.4 % → −14.1 %)—— 因為分子在 337 nm、 分母在 750 nm,它量的主要是視窗結垢。

8. 重測這次實驗需要改的四件事

  1. 先確認閥門真的送氣。 這是唯一真正重要的一條。光譜不能當成閥門的佐證 (這次就是這樣失敗的)。獨立佐證可以是:關閥/開閥時的腔體壓力變化、 RGA、或是在沒有電漿的狀態下開到 index 200 後量 rate-of-rise。
  2. 先安裝站點設定(§7.2)。 否則 app 當天的輸出再次不可讀,而且會再次產生一個 與實驗無關的 Alarm 污染判讀。順便重建 Golden Run —— §6.1 已經證明這一天的資料品質足夠。
  3. 劑量順序不要單調遞增。 這次靠 16:45 的長清洗意外解開共線(§2.2),不能指望第二次。 最小的修正是 0 → 200 → 0 → 100 → 0 …,讓每個劑量都有一個時間上相鄰的零點。
  4. 每個劑量至少等 2τ。 計畫 §15.2 算出 400 L / 500 sccm 的時間常數是 19–126 s(視壓力), 而這次每個閥位只跑了一支 79 s 的 C。如果閥門其實有送氣但只送了一點, 單支 step 可能還沒到穩態 —— 這是讀法 A 之外唯一沒被完全排除的可能, 雖然 §4.3 的 ±1 % 讓它很難成立。

另外建議:重測時把 B 跑在與生產相同的操作點,而不是 3.8 torr 的清潔條件。 §6.2 的數字只對這次的 B 成立,而計畫要判的是生產時的 B。

9. 這次分析不能回答的

  • GO/NO-GO。 見 §5。
  • TEOS 對 k 的折損(計畫 §15.4 風險 1)。 仍然未量化,仍然是那 8.3 倍餘裕的唯一用途。
  • ArUV 橋樑搬不過來。 2026-09-04 用 415–436 nm 的 Ar I 多重線當跨機台橋樑(該分析 §4.1), 這次無法重現:製程 C 在 405–445 nm 全段都是密集發射, 側窗 411.5–413.5 壓在一條 6300 counts 的結構上,band mean 4119 減側窗基線後是負值。 在 TEOS 電漿裡這個區段沒有乾淨連續光。 這不影響本次結論(沒有劑量可量), 但下次要做跨機台外推時必須另尋橋樑。
  • R_N2CO_C 是不是又一個「假贏家」。 §6.1 證明它穩定, 但計畫 §3.1 的教訓正是「穩定不等於有用 —— CV 低得異常本身就是壞掉的證據」。 它對漏氣有沒有反應,這一天沒有測到。在 §8 的重測完成之前,這個問題是開著的。
