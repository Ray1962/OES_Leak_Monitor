   但**是跟著時間走,不是跟著閥位走**,N₂ 帶頭相對於自己兩側沒有多出任何東西。

   也不是漏氣的證據**(§4.3)。它與 CO 349 的比值在 12 支 A 裡固定在 0.399(CV 2.8 %),

   稀釋後只有約 19 ppm 的空氣,預期的 N₂ 上升是 +1 %～+3 %,**在這個光量下本來就看不到**。
   所以這一天既不能證明閥門沒送氣,也不能證明指標不靈 —— 它根本測不到這個量級。

   計畫 §16 的 GO 改判 NO-GO**(可偵測漏率是規格的 3.2～7.3 倍)。

在這個順序下都會畫出一樣的圖。

#### 09-20 的「N₂ 337」也是同一個東西,不是從別處漏進來的空氣

使用者確認製程裡沒有 N₂,並問:09-20 讀到的 N₂ 337 會不會是空氣從別的地方(例如 TEOS 管線)漏進腔體?
`11_n2_0920.py` 把 09-20 全部 35 筆錄檔的 337 nm 附近拆開來看。**答案是:那個讀值不是氮發出來的光。**

| 檢查 | 若是 N₂ 應該看到 | 09-20 實測 |
|---|---|---|
| 位置 | 帶頭 337.13,峰在其藍側 | 峰在 **338.2–338.6**,比 N₂ 帶頭紅約 1 nm;藍側(334–336.7)是平的,紅側拖到 345 |
| 形狀擬合(16:45 長清洗,特徵高 1553) | N₂ 形狀吻合 | 殘差:紅向帶 189、**N₂ 形狀 539**;兩者並用時 N₂ 項是 +103 ± 153(零) |
| (0,1) 帶頭 357.69 —— 與 (0,0) 同一個上能階,強度必為其約 0.67 倍 | 16:45:**+1041**;15:48–15:59:+300～+340 | **−32**;**−11～−21**(完全沒有帶頭) |
| 跟誰一起變 | 與碳無關 | 與 **CO₂⁺ 288.3/289.6 雙線**同進退:特徵從 35 到 1553 counts(44 倍)、四種電漿,兩者比值都在 **0.16～0.37** |

第三列是最硬的一條:同一個上能階出來的兩條帶,分支比是固定的,不可能只出現一條。
長清洗裡 337 特徵有一千五百多 counts,357.7 卻連 30 counts 的帶頭都沒有 —— **其中的氮不到 3 %**。
(製程 C 的 357.7 讀值是很大的負值,那是側窗踩在 356 nm 另一個隆起上,在 C 裡這一項不能用。)

第四列同時把 §4.3 (2) 的物種推定補實了:288.3/289.6 這組雙線是 CO₂⁺ 的標誌,
加上 325–326 與 350–351.5 nm 的同伴帶,**337–345 nm 那個特徵是 CO₂⁺**,來源是 TEOS 的碳被氧化成 CO₂。
它在鍍膜後的長 O₂ 清洗裡最強(`337/CO330` = 0.21～0.26),在 C 是 0.020、B 是 0.012 ——
各製程一個固定值,而且在 16:45 那支長清洗的 140 秒裡一直穩定在 1060～1095。

**這也解釋了 `R_N2CO_C` 為什麼穩得出奇(跨錄檔 CV 3 %):分子分母都是碳氧化物。**
計畫 §3.1 警告過「CV 低得異常本身就是壞掉的證據」,這是同一個陷阱的第四次。
真正漏進來的 N₂ 仍然會加在這個窗口上(09-04 實驗機台量到的線性沒有錯),
所以指標不是瞎的;但它的無漏讀值量的是 CO₂⁺,不是殘留的氮。

**能排除到哪裡:** 沒有任何一筆錄檔的 N₂ 形狀成分顯著大於零。換算成空氣量,
這個方法在 30 slm 下的鑑別力大約是**數 sccm**(§4.4 的同一個限制)——
也就是說,它排除了「337 的讀值來自漏氣」,排除不了「另外有一個幾 sccm 以下的漏」。
後者要靠 rate-of-rise 或氦測漏,光譜做不到。

> **附帶更正:紫外端的波長軸偏移是約 +0.10 nm,不是 +0.30。** Si 288.16 讀到 +0.09、Hβ 486.13 讀到 −0.05,
> Hα、O 777、O 844 才是 +0.24～+0.27。計畫的 +0.30 是用 690 nm 以上的 Ar I / O I 線量的,
> 不能套到 337 nm。站點設定裡 N₂ 337 的中心(337.40)應該是約 337.2。

### 4.4 這兩支配方把漏氣稀釋到看不見

資料夾裡那份配方記錄(§1.2)給了流量,單位是 sccm(使用者 2026-10-01 確認):

| | 製程 A | 製程 B | 計畫 §16.1 的假設 |
|---|---|---|---|
| 總流量 | Ar 9500 + He 17000 + O₂ 4000 ≈ **30 500** | Ar 3000 + He 18000 + O₂ 15000 = **36 000** | 500 |
| DV 200(1.0×10⁻² mbar·L/s = 0.59 sccm)的空氣比例 | **1.9×10⁻⁵** | **1.6×10⁻⁵** | 1.2×10⁻³ |
| 依 §16.2 的 s 換算,DV 200 的 N₂ 上升 | **+1.4 %～+3.3 %** | — | +87 %～+200 % |

**同樣的漏率,在這兩支配方裡被稀釋了 60–70 倍。** 一個 +1 %～+3 % 的上升,落在一個只占視窗 7 %、
逐幀 SNR 5–7 的帶頭上,是量不到的。

這改變了這一天的讀法:**「沒看到」在這裡是預期中的結果,不管閥門有沒有送氣。**
它同時也表示:以規格漏率(8.89×10⁻³ mbar·L/s)為目標的監測,在 30 slm 等級的配方上
靠 N₂ 發光是做不到的 —— 這是對計畫本身的問題,不只是對這次測試。

**09-20 的配方流量也是這個量級**(使用者確認)。那份分析假設的是 500 sccm,所以要改寫:

| | 09-20 當時的讀法 | 以實際流量重算 |
|---|---|---|
| index 200 的空氣比例 | 1.2×10⁻³ | **約 1.9×10⁻⁵** |
| `R_N2CO_C` 的預期上升 | +77 %～+178 % | **+1.4 %～+3.3 %** |
| 實測 | +1.9 % | +1.9 % —— **落在預期範圍內**,但跨錄檔 σ 是 2.97 %,不顯著 |
| 判讀 | 閥門沒有送氣 | **撤回。** 資料與「閥門照對照表送氣」完全相容,也與「沒送氣」相容 |

那份文件 §5 自己寫過另一種讀法 ——「閥門送了,指標差 46 倍,Q_det = 4.97×10⁻²,NO-GO」——
當時因為解釋不了其他十一個特徵也是零而被否決。**稀釋 61 倍同時解釋了全部十二個**,
46 倍與 61 倍在 σ 之內就是同一個數字。

對計畫 §16 的後果(製程 A/C,30 500 sccm = 515 mbar·L/s):

| | 500 sccm(原判) | 30 500 sccm |
|---|---|---|
| 可偵測漏率(保守 k) | 1.07×10⁻³ mbar·L/s | **6.5×10⁻² mbar·L/s**(≈ 7.3 mTorr/min) |
| 可偵測漏率(E3 的 k) | 4.65×10⁻⁴ | **2.8×10⁻²**(≈ 3.2 mTorr/min) |
| 相對規格 8.89×10⁻³(1 mTorr/min) | 餘裕 8.3～19 倍 | **差 3.2～7.3 倍 → NO-GO** |

也就是說,以 N₂/CO 發光監測,在這個流量下能抓到的是 **3～7 mTorr/min 以上**的漏氣,
抓不到 1 mTorr/min。這還沒有算 §2 的光量損失與 TEOS 對 k 的折損(計畫 §15.4),兩者都只會更差。

## 7. 再測之前要做的事

1. **獨立確認閥門送氣。** 不開電漿、隔離抽氣,在 DV 0 / 100 / 200 各量一次腔體
   rate-of-rise(或看 RGA 的 m/z 28、32)。那張 `0 → 0.9` 的表把它填完。
   **這一條沒做完,其他幾條都不值得做。**
2. **在低流量的配方上測。** 要讓 DV 200 的空氣比例回到 10⁻³ 量級,總流量得在 1 slm 以下
   (或是把漏率加到 0.3 mbar·L/s 以上,那已經不是規格大小的漏氣)。**在 30 slm 的配方上重跑幾次都一樣。**
   **真正要先回答的是:規格能不能放寬到 3～7 mTorr/min,或有沒有低流量的步驟(抽氣後、通氣前)可以拿來量。**
3. **先解決光量。** 在同一支 09-20 的配方上跑一段,就能判斷是光路(光纖、準直鏡、視窗)
   還是配方。若是配方,考慮把積分時間拉長 —— A 的最大值只有 3100 counts,
   離飽和還很遠,8–10 倍的積分時間可以把紫外拉回 09-20 的水準(代價是幀率)。
4. **閘門門檻降到約 600。** 目前 B 只有 6–10 % 餘裕;電漿關閉時的 p99 是 108–395,600 兩邊都有餘裕。
5. **Golden Run 只在 DV 0 擷取,而且一支製程一個名字。** 或是開分類器、每個比值設
   `processClass`,讓一份 Golden Run 同時帶 A 與 B 的基準。
6. **劑量順序打散**:0 → 200 → 0 → 100 → 0 → 200 …,每個劑量旁邊都要有時間上相鄰的零點。
   A 這次的單調順序加上 2.4 倍的暖機漂移,畫出了一條看起來像劑量反應的曲線(§4.3)。
7. **每支配方先暖機再開始計數。** A 連續跑了半小時還沒到穩態;
   先空跑幾支,等 Ar 750 穩下來再開始 DV 0。

## 8. 這次分析不能回答的

- **閥門到底有沒有送氣**:光譜只能說「沒看到」。§7 第 1 條才是答案。
- **光量掉的原因**:使用者確認 09-20 與 09-28 是同一組配方,所以紫外 1/10、近紅外 1/25～1/100 的落差**不是配方造成的** ——
  是光路或電漿狀態在這八天之間變了(兩天的段長也不同:C/A 79 → 63 s、B 105–110 → 97 s)。原因未知,值得現場查。
- **有沒有一個幾 sccm 以下、與測漏閥無關的漏**(例如 TEOS 管線):光譜在這個流量下看不到,要用 rate-of-rise 或氦測漏。

- **B 對空氣的靈敏度**:B 的 N₂ 帶頭本來就量不到,這次沒有任何劑量讓它出現過。
- **A 的暖機漂移是什麼**:NIR 漲 2.4 倍、CO 330 先漲後跌,可能是腔壁溫度或鍍膜狀態,
