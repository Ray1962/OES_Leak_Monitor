## 4. 外推到生產機台

### 4.1 為什麼不能用 Ar 750.4 當橋樑

實驗機台把 **N₂ 337 量在 OES2、Ar 750 量在 OES1**,兩台不同的光譜儀、各自未經輻射校正。
`N₂337(OES2 counts) / Ar750(OES1 counts)` 這個數字**沒有物理意義可以搬到別台機器上**。

實測的證據:`ArUV/Ar750` 在實驗機台是 0.14~0.17,在生產機台是 **0.026** —— 差 6 倍。
那不是電漿差異,是兩台光譜儀在 425 nm 與 750 nm 的相對響應差異。
用 Ar 750 當橋樑會得到 φ_min ≈ 1.5×10⁻⁵ 這種**過度樂觀 3~7 倍**的數字。

所以橋樑必須是**同一台偵測器上、而且波長靠近 337 的參考**:
415–436 nm 的 Ar I 多重線(ArUV)。337 與 426 相距 89 nm,兩台光譜儀在這個區間的
相對響應差異遠小於 337 對 750。

> **這是本次分析裡唯一一個「換個算法就差 5 倍」的地方。** 記下來,因為它下次還會出現。

### 4.2 生產機台的無漏讀值

|---|---|---|
| N₂ 337 peak height | **467.1** | 154.8(33 %) |
| ArUV | 804.8 | — |
| `R = N₂337/CO330` | **0.02162** | 0.00152(**7.0 %**) |

(同一份資料用帶內平均抽取是 144.0 與 0.01080 —— 見 §2.1 的警告,那組數字不能拿來外推。)

`R` 在兩天全部 C 段上的散度 7.0 %,而計畫 §3 在**固定取樣點**上量到的是 3.1 % ——
差的那一截正是批次內視窗結垢的漂移,也就是 P2 那一整層存在的理由。這一致性同時說明
本次抽取重現了計畫當初的設定。

## 5. 體積不進來,但時間會

**穩態的光譜訊號只取決於漏氣佔總流量的比例,與腔體體積無關。**
穩態下任一物種的分壓 = 它的流量 ÷ 抽速,兩種氣體被同一套幫浦抽,所以
N₂ 與 O₂ 的比例就是它們流量的比例。15 L 換成 400 L 不改變這件事。

體積改變的是**時間常數** τ = V·P/F —— 漏氣開始之後多久才到穩態:

| 情境 | τ |
|---|---|
| 實驗機台 E1 / E2 / E3 | 13.0 / 9.8 / 12.3 s |
| 生產 400 L,1 torr,100 sccm | 316 s |
| 生產 400 L,1 torr,250 sccm | 126 s |
| **生產 400 L,500 sccm(實際值),0.3 / 0.5 / 1 / 2 torr** | **19 / 32 / 63 / 126 s** |

生產機台的電漿步驟長約 **84 s**。**實際總流量是 500 sccm**(2026-09-04 確認),
所以 τ 落在 19～126 s,也就是**約一個步驟的等級** —— 漏氣訊號在一到兩個步驟之內就到穩態。

> ### 更正
>
> 本文初稿寫的是「一個剛出現的漏氣在單一步驟之內根本到不了穩態」。
> 那是用 100 sccm 估的;**在實際的 500 sccm 下這句話不成立**,τ 只有一個步驟上下。
>
> 跨批次層仍然是主力,但理由是**視窗結垢**(同一批之內的幀彼此不可比),
> 不是時間常數。逐幀路徑也仍然有效,只是靈敏度較差 —— 見計畫 §16.3 的兩條路徑對照。

反過來說,實驗機台 10～13 s 的 τ 讓每一筆 60 s 錄檔都穩穩落在穩態 —— 上面的劑量曲線可信。

## 6. GO / NO-GO:目標數字要重算

計畫 §5.1 的 `Q_min = 1×10⁻⁴ mbar·L/s` 是從「rate-of-rise 1 mTorr/min × 腔體約 50 L」推的。
**腔體實際是 400 L,這個數字必須重算**,而且方向對本計畫有利:同樣的 rate-of-rise 規格
套在更大的腔體上,允許的漏率就更大。

    Q = (rate-of-rise) × V

| rate-of-rise 規格 | × 400 L → Q |
|---|---|
| 1 mTorr/min | 8.9×10⁻³ mbar·L/s |
| 0.3 mTorr/min | 2.7×10⁻³ |
| 0.1 mTorr/min | 8.9×10⁻⁴ |
| 0.03 mTorr/min | 2.7×10⁻⁴ |
| 0.01 mTorr/min | 8.9×10⁻⁵ |

把它和 §4.3 的偵測能力擺在一起(取 500 sccm、E2 的保守 k,Q_det = 6.1×10⁻⁴):

| 規格 | 目標 Q | 餘裕 |
|---|---|---|
| 1 mTorr/min | 8.9e-3 | **15 倍,明確 GO** |
| 0.3 mTorr/min | 2.7e-3 | 4.4 倍,GO |
| 0.1 mTorr/min | 8.9e-4 | 1.5 倍,勉強 |
| 0.03 mTorr/min | 2.7e-4 | **不足,NO-GO** |
| 舊的 1e-4 目標 | 1.0e-4 | 不足 6 倍 |

### 6.1 兩個數字已經到手 —— **GO**

2026-09-04 確認:**製程 C 總流量 500 sccm**、**漏率規格 1 mTorr/min**。

| | |
|---|---|
| 總流量 | 500 sccm = **8.444 mbar·L/s** |
| 目標漏率 | 1 mTorr/min × 400 L = **8.89×10⁻³ mbar·L/s** |
| 可偵測(保守 k,E2) | **1.07×10⁻³ mbar·L/s** → **餘裕 8.3 倍** |
| 可偵測(E3 的 k) | 4.65×10⁻⁴ mbar·L/s → 餘裕 19.1 倍 |

**GO,而且不是勉強過關。**

規格大小的漏氣在 `R_N2CO_C` 上不是一個 9.3 % 的邊緣訊號,而是

    +360 counts(保守)～ +830 counts,對上無漏的 467 counts
    = **+77 % ～ +178 %**

也就是**讀值會變成兩到三倍**。這個餘裕的意義在於它**吸收得掉 §7 那條沒有量化的風險**:
就算 TEOS 把 k 砍掉八倍,仍然偵測得到規格大小的漏氣。

順帶得到洩漏率校正的靈敏度(P5 用):

    x = s × Q,  s = 86.6（E2 的 k）～ 200（E3 的 k） per (mbar·L/s)

其中 x 是 `R_N2CO_C` 相對無漏基準的分數上升量。

## 7. 這次實驗不能回答的事

1. **實驗機台沒有 TEOS。** 這是最大的一條。已經處理掉的部分:外推用的是
   **生產機台自己的無漏讀值(144 counts)與自己的跨批次 σ(3.1 %)**,
   所以 TEOS 連續光把 337 墊高、以及它帶來的散度,都已經算在裡面了。
   **沒有處理掉的部分**:k 本身可能因為 TEOS 而改變。含碳電漿裡漏進來的 N₂
   會有一部分變成 CN/HCN 或進到膜裡,那會**減少** N₂ 337。這個折損目前無法量化,
   可能是幾成,也可能是幾倍。
2. **CN 388 不是零背景指標。** 原本期待「無氮的含碳電漿裡 CN 應該是零,所以任何 N 進來都會亮」,
   但生產機台無漏時 388 nm 就讀到 1204 counts(是 ArUV 的 1.5 倍),散度 25 %。
   那個窗口在 TEOS 電漿裡本來就有東西(CH/C₂/CO 都在附近),
   **不要把它當成 CN,也不要當成漏氣指標** —— 這是一個看起來很好、實際上不成立的想法,
   和計畫 §3 記下的那三個一樣。
3. **N₂ 357.7 在生產機台上讀到負值**(−239),它的連續視窗高於帶本身。
   實驗機台上 357.7 是第二強的指標,**但它搬不過去**。只有 337.1 兩邊都成立。
4. **兩台光譜儀的相對輻射響應**沒有校正,只用「337 與 426 靠得夠近」來論證。
   這是外推裡最後一個未量化的假設,估計影響在 1.5 倍以內。
5. **對照表的絕對值。** 見 §1.1。

## 8. 對程式的影響

**沒有需要改的程式碼。** 這份資料驗證的是既有設計的三個選擇:

- **N₂ 337.1 是對的指標** —— 它比第二名強 1.7~2.4 倍,而且是唯一一個在兩台機器上都成立的。
- **Ar 750.4 / 811.5 是對的參考線** —— 20 倍的 N₂ 變化裡它們動不到 1 %。
- **跨批次層(P2/P3)是主力而不是備案** —— §5 的時間常數說明逐幀判定在 400 L 上做不到。

**這份資料不能當成生產機台的 `LeakCalibration` 匯入**:機台不同、沒有 TEOS,
而校正在程式裡是綁定某一份 Golden Run 的。它是**選指標與估靈敏度的依據**,不是校正係數。
