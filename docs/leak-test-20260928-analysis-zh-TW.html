(4) 它跟著時鐘走。 17:00 那支 A(測試開始前,閥門沒開)是 21,19:50 的 DV 0 是 28 —— 沒有動閥門就差了 34 %,和 DV 0 → DV 100 的第一步(28 → 35.5)一樣大。 DV 100 三支閥門沒動,帶頭 35.5 → 39.3 → 46.6;DV 200 七支橫跨 20 分鐘,停在 50 不動。 這是「連續跑 A、腔體逐漸到穩態」的曲線。同一段時間穿插的 B(19:56)帶頭仍是基準值。

之所以「看起來」隨 DV 增加,是因為 A 的 DV 嚴格隨時間遞增:任何隨時間單調變化的量, 在這個順序下都會畫出一樣的圖。

第三列是最硬的一條:同一個上能階出來的兩條帶,分支比是固定的,不可能只出現一條。 長清洗裡 337 特徵有一千五百多 counts,357.7 卻連 30 counts 的帶頭都沒有 —— 其中的氮不到 3 %。 (製程 C 的 357.7 讀值是很大的負值,那是側窗踩在 356 nm 另一個隆起上,在 C 裡這一項不能用。)

第四列同時把 §4.3 (2) 的物種推定補實了:288.3/289.6 這組雙線是 CO₂⁺ 的標誌, 加上 325–326 與 350–351.5 nm 的同伴帶,337–345 nm 那個特徵是 CO₂⁺,來源是 TEOS 的碳被氧化成 CO₂。 它在鍍膜後的長 O₂ 清洗裡最強(337/CO330 = 0.21～0.26),在 C 是 0.020、B 是 0.012 —— 各製程一個固定值,而且在 16:45 那支長清洗的 140 秒裡一直穩定在 1060～1095。

這也解釋了 R_N2CO_C 為什麼穩得出奇(跨錄檔 CV 3 %):分子分母都是碳氧化物。 計畫 §3.1 警告過「CV 低得異常本身就是壞掉的證據」,這是同一個陷阱的第四次。 真正漏進來的 N₂ 仍然會加在這個窗口上(09-04 實驗機台量到的線性沒有錯), 所以指標不是瞎的;但它的無漏讀值量的是 CO₂⁺,不是殘留的氮。

能排除到哪裡: 沒有任何一筆錄檔的 N₂ 形狀成分顯著大於零。換算成空氣量, 這個方法在 30 slm 下的鑑別力大約是數 sccm(§4.4 的同一個限制)—— 也就是說,它排除了「337 的讀值來自漏氣」,排除不了「另外有一個幾 sccm 以下的漏」。 後者要靠 rate-of-rise 或氦測漏,光譜做不到。

7. 再測之前要做的事

  1. 獨立確認閥門送氣。 不開電漿、隔離抽氣,在 DV 0 / 100 / 200 各量一次腔體 rate-of-rise(或看 RGA 的 m/z 28、32)。那張 0 → 0.9 的表把它填完。 這一條沒做完,其他幾條都不值得做。
  2. 在低流量的配方上測。 要讓 DV 200 的空氣比例回到 10⁻³ 量級,總流量得在 1 slm 以下 (或是把漏率加到 0.3 mbar·L/s 以上,那已經不是規格大小的漏氣)。在 30 slm 的配方上重跑幾次都一樣。 真正要先回答的是:規格能不能放寬到 3～7 mTorr/min,或有沒有低流量的步驟(抽氣後、通氣前)可以拿來量。
  3. 先解決光量。 在同一支 09-20 的配方上跑一段,就能判斷是光路(光纖、準直鏡、視窗) 還是配方。若是配方,考慮把積分時間拉長 —— A 的最大值只有 3100 counts, 離飽和還很遠,8–10 倍的積分時間可以把紫外拉回 09-20 的水準(代價是幀率)。
  4. 閘門門檻降到約 600。 目前 B 只有 6–10 % 餘裕;電漿關閉時的 p99 是 108–395,600 兩邊都有餘裕。
  5. Golden Run 只在 DV 0 擷取,而且一支製程一個名字。 或是開分類器、每個比值設 processClass,讓一份 Golden Run 同時帶 A 與 B 的基準。
  6. 劑量順序打散:0 → 200 → 0 → 100 → 0 → 200 …,每個劑量旁邊都要有時間上相鄰的零點。 A 這次的單調順序加上 2.4 倍的暖機漂移,畫出了一條看起來像劑量反應的曲線(§4.3)。
  7. 每支配方先暖機再開始計數。 A 連續跑了半小時還沒到穩態; 先空跑幾支,等 Ar 750 穩下來再開始 DV 0。

8. 這次分析不能回答的

  • 閥門到底有沒有送氣:光譜只能說「沒看到」。§7 第 1 條才是答案。
  • 光量掉的原因:使用者確認 09-20 與 09-28 是同一組配方,所以紫外 1/10、近紅外 1/25～1/100 的落差不是配方造成的 —— 是光路或電漿狀態在這八天之間變了(兩天的段長也不同:C/A 79 → 63 s、B 105–110 → 97 s)。原因未知,值得現場查。
  • 有沒有一個幾 sccm 以下、與測漏閥無關的漏(例如 TEOS 管線):光譜在這個流量下看不到,要用 rate-of-rise 或氦測漏。
  • 388.9 與 391.3 nm 那一對特徵是什麼:四種電漿裡都有,位置對不上 N₂⁺(427.8 沒有對應的帶頭)也對不上 CN,未辨認。
  • B 對空氣的靈敏度:B 的 N₂ 帶頭本來就量不到,這次沒有任何劑量讓它出現過。
  • A 的暖機漂移是什麼:NIR 漲 2.4 倍、CO 330 先漲後跌,可能是腔壁溫度或鍍膜狀態, 這份資料沒有能分辨的量。
