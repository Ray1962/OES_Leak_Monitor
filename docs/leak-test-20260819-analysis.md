## 1. 三個結論

1. **看到的「上升」不是洩漏**。`N2 337.1 [R_102ba093]` 在 18:01:31 從 78.7 跳到 567.8（7.2 倍），
   但同一幀 `Ar 750` 也從 10152 跳到 35566（3.5 倍）——那是電漿點燃。而該監看量有 **76 % 是連續背景**，
   電漿一亮整片抬起來。把背景減掉之後，氮在兩份記錄裡**從頭到尾只有單調下降，沒有任何階梯**。

2. **洩漏閥 100 單位 vs 50 單位，光譜上量不出差別**。兩者的 `N₂337/Ar750` 差 11 %，而當天
   **沒有動過閥門的六次 run 之間，每次也都掉 9–11 %**。閥門的貢獻落在這條既有的衰減曲線裡，
   分不出來。

3. **原因是腔體還沒抽乾淨**。17:34 拆掉觀察窗壓克力板時腔體開過大氣，之後所有空氣來源的譜線
   （N₂、NO、OH、N₂⁺）以約 **32 分鐘的時間常數**持續衰減，到 18:01 仍在進行中；製程氣體
   （Ar、O）幾乎不動。**測試是在一個比訊號大 2–3 倍、而且正在變化的空氣背景上做的。**

## 2. 「N₂ 337 上升」是電漿點火

`P_Ratio_0819180111.csv` 的前兩筆有值資料：

| 時間 | `N2 337.1` (RawMean) | `Ar 750`（回推） | `N₂337/Ar750` |
|---|---|---|---|
| 18:01:29 | 78.7 | 10 152 | 0.00775 |
| 18:01:31 | 567.8 | 35 566 | 0.01596 |

**氮和氬在同一幀一起跳**，441 nm 連續背景同步抬升。這是電漿從點燃到全開，不是氣體成分改變。

而該項監看的量本身混著背景：

```
18:01:31 峰值幀
  N2 337.1   RawMean = 567.8    PeakHeight（減連續背景）= 136.0   → 峰只佔 24 %
  N2 357.7   RawMean = 1018     PeakHeight = 39.3   SNR = 0.4     → 這個波長上沒有可用的線
  Ar 750.4   RawMean = 28 470   PeakHeight = 35 666  SNR = 39
  O  777.4   RawMean = 21 061   PeakHeight = 25 663  SNR = 274
```

減掉連續背景後，`N2 337` 峰高在測試 2 內部是 **136 → 104**（−24 %），單調下降，
**開閥的時間點附近沒有任何階梯**。測試 1 同樣沒有。

> 這正是 `RatioDefinition.ValueHasPedestal` 在處理的狀況：`RawMean` 不減背景，所以它的值
> 大部分是連續背景，而連續背景跟著電漿亮度走。詳見
> [`golden-run-baseline-troubleshooting-zh-TW.md`](golden-run-baseline-troubleshooting-zh-TW.md) §2.2。

## 4. 整個下午都在抽殘留空氣

衰減不是光路造成的，是氣體本身。決定性的證據是**氮掉得比背景快**：

| 測試 2 內部（0 → 72 秒） | 變化 |
|---|---|
| N₂ 337 峰高 | −23.6 % |
| 441 nm 連續背景 | −9.9 % |

若是鏡片鍍膜或光纖劣化，同一波長區的譜線與背景應該一起衰減。氮掉的速度是背景的 **2.4 倍**，
所以是**氮本身在減少**。

其餘證據一致：

- **只有空氣來源的物種在掉**：N₂ 337 −57 %、NO 237 −69 %（27 分鐘內）；製程氣體 Ar 750、
  O 777、Ar 811 只掉 2–6 %。
- **NO 掉得比 N₂ 快**：NO 由 N 與 O 反應生成，正比於兩者的乘積，所以空氣分壓下降時它衰減更陡。
  這是「空氣正在被抽走」的指紋。
- **時間常數約 32 分鐘**（7.303 → 3.145 歷時 27.1 分鐘），到 18:01 仍未走平。

現場筆記寫著 17:34「撤掉視窗壓克力板，第一次測試」——**那次拆裝把腔體開到了大氣**，
之後的每一次 run 都是在同一次抽真空的過程中做的。

*（次要效應）* 在單次 run 內，各譜線的衰減幅度嚴格依波長排序：309 nm −17.7 %、337 nm −16.2 %、
391 nm −12.9 %、441 nm −10.8 %、656 nm −6.0 %、750 nm −4.4 %、811 nm −3.9 %。這一項是光路的
紫外選擇性衰減（鍍膜／光纖），幅度比抽氣效應小，但**存在**，而且會讓紫外的洩漏指標長期鈍化。

## 5. 重測程序

1. **等腔體抽乾淨。** 持續看 `N₂337/Ar750`（或 N₂ 337 的減背景峰高），直到它不再每分鐘掉約 1 %。
   依 32 分鐘的時間常數推算，腔體開過大氣之後**至少要 2 小時**才接近平衡。
2. **先錄無洩漏基準。** 在同一個電漿條件下錄滿至少一分鐘。這兩份記錄裡**都沒有「零洩漏」參考點**，
   所以只能比較 100 vs 50，無法回答「有漏 vs 沒漏」。
3. **每個閥門設定維持數分鐘**，不要用 80 秒的 run。要看得到階梯、也要有前後對照。
   建議序列：無洩漏 3 min → 50 單位 3 min → 無洩漏 3 min → 100 單位 3 min → 無洩漏 3 min。
4. **調低記錄器的 save 門檻**，讓全光譜記錄在電漿點燃**之前**就開始。目前它是點燃後才開檔，
   所以每次測試都丟掉了自己的參考點（`P_OES1_0819180131.csv` 的第一幀就已經是峰值）。
5. **不要跨越 step 切換。** 兩份記錄在 74–78 秒都有一次製程切換：`Ar 750` 掉 60 %、`O 777` 漲 48 %。
   任何除以 Ar 750 的比值在那個瞬間都會跳 2.5 倍，與洩漏無關。一份 Golden Run 只能描述一個操作點
   （見 [`adr/0001`](adr/0001-golden-run-is-one-steady-operating-point.md)）。

## 6. 順帶發現的設定問題

| 項目 | 實測 | 建議 |
|---|---|---|
| `N2 337.1 [R_102ba093]`（`RawMean`） | 峰只佔 24 %，其餘是連續背景 | 改用 `PeakHeight`（實測 SNR 6.7，可用），真訊號才不會被稀釋 4 倍 |
| `N₂ 358 absolute` / `N2 358 / Ar750` | 357.7 nm 的 **SNR = 0.4**，峰高 39 對 RawMean 1018 | **這個波長上沒有可用的譜線**，兩項都在量連續背景，建議停用或換線 |
| 作用中的 Golden Run | 比值檔顯示 `_pctBaseline` 全程只有 25–56 % | 基準是在完全不同條件下錄的（不同積分時間／壓克力板／空氣背景），**已不適用**，需重錄 |
| 警報狀態 | 測試 2 一開始就是 `Warning` | 那是測試 1 留下的鎖存未 Acknowledge，不代表測試 2 有事 |

`NO 237` 是這批資料裡除了 Ar／O 之外唯一穩定可用的譜線（SNR 7.8，峰高 210，
且峰高幾乎等於 RawMean——該處連續背景很低）。它與 N₂ 337 的變化方向一致，
可作為第二個獨立意見。

## 附錄 B：分析方法

譜線強度是用 `LineIntensityExtractor` 的演算法在 Python 裡重做一遍算出來的
（`PeakHeight`：峰值搜尋 ±1 nm、訊號窗 ±0.5 nm、兩側背景窗 gap 1 nm / width 1 nm、
線性內插連續背景；`RawMean`：不減背景、不搜峰，±0.5 nm 分數像素加權平均）。

該重做過的萃取器**先對照本機 `settings.json` 裡已存的 Golden Run 基準驗證過**：
用同一段時間窗重算 `N2 337.1 / Ar 750.4` 與 `uN2 335.5 / Ar 750.4`，結果與 app 實際存進去的
`mean`、`σ`、`sampleCount` **一致到顯示精度（Δ 0.00 %）**。驗證時發現必須套用
`LeakMonitorSettings.WavelengthCorrections`（`Ar 750.4 +0.4`、`N2 337.1 +0.2`），
否則會差 24.9 %。

本文所有「峰高」都是減掉連續背景後的值，除非明確標示 `RawMean`。
