# Species Ratio 槽位 SVID 範例說明

> 本文以設備出廠比值組為例，說明 Ratio Setup 中每一組 Species Ratio 對應的 SVID 怎麼算、讀到的值代表什麼。
> 依據：`docs/Satellite_SECS_Specification_v2.md` §1.4(b)～(d)、§6.2。

> **實作狀態：** 比值槽位 VID 101～400（位移 01～25）與 CEID 507 已由設備端實作（規格 v2.4），可用 S1F3 查詢、S2F23 追蹤。
> 第 3、5 節的身分類數值是出廠比值組實際會送出的值；第 4 節的即時量是虛構的範例值。
> 舊機台的 profile 若是 2026-10-23（加入槽位 VID）之前寫的，要先在 SECS 分頁按「Add missing rows」並重啟介面，才查得到這些 SVID。

## 1. 編碼規則

SVID 為 10 位數 `1ccssaavvv`。OES Leak Monitor 的 `ss` 固定為 `27`，`aa` 固定為 `00`（OES 不經 slit valve），`cc` 為腔體代號。比值槽位的 `vvv` 由下式決定：

```
SVID = 1 + cc + 27 + 00 + vvv
vvv  = 100 + (N − 1) × 30 + 位移        （N = Ratio Setup 的第 N 列，1～10）
```

每個槽位佔 30 個號碼，號碼範圍為 `[100+(N−1)×30+1, 100+N×30]`：

| 槽位 | 起算值（位移 0） | VID 區段 | 槽位 | 起算值（位移 0） | VID 區段 |
|---|---|---|---|---|---|
| Ratio 1 | 100 | 101～130 | Ratio 6 | 250 | 251～280 |
| Ratio 2 | 130 | 131～160 | Ratio 7 | 280 | 281～310 |
| Ratio 3 | 160 | 161～190 | Ratio 8 | 310 | 311～340 |
| Ratio 4 | 190 | 191～220 | Ratio 9 | 340 | 341～370 |
| Ratio 5 | 220 | 221～250 | Ratio 10 | 370 | 371～400 |

> **算一次：** Ch_2 的 Ratio 2「基準百分比／σ 分數」（位移 03）
> = `100 + (2 − 1) × 30 + 03` = VID `133`
> → SVID = `1` + `02` + `27` + `00` + `133` = **`1022700133`**

本文以下範例一律假設設備裝在 **Ch_2（`cc = 02`）**。

## 2. 範例設定：出廠比值組

Ratio Setup 分頁的出廠內容（`LeakMonitorSettings.CreateDefault()`）共四列。槽位號就是畫面上的列號：

| 槽位 | Key | 訊號線 | 參考線 | 監測方式 | 擷取方式 | 啟用 |
|---|---|---|---|---|---|---|
| Ratio 1 | `R_N2Ar` | N₂ 337.1 nm | Ar 750.4 nm | 比值 | RawMean | ✔ |
| Ratio 2 | `R_NOAr` | NO 237.0 nm | Ar 750.4 nm | 比值 | RawMean | ✔ |
| Ratio 3 | `R_N2357Ar` | N₂ 357.7 nm | Ar 750.4 nm | 比值 | PeakHeight | ✔ |
| Ratio 4 | `R_N2357Abs` | N₂ 357.7 nm | —（不使用） | 絕對強度 | RawMean | ✘ |

Ratio 5～10 沒有設定，是**空槽位**：照常回應，位移 16 = 0、05 = 6（Disabled），數值都是 0，字串（22～25）都是空字串。看位移 25 是否為空，就能分辨「空槽位」與 Ratio 4 這種「有設定但停用」。

## 3. 身分類 SVID（位移 16～25）

這一組 SVID 描述「這個槽位在監測什麼」，只在比值設定重新載入（設備重新開始採集）時可能改變；改變時設備送 CEID `10227507`。Host 讀這一組就能知道每個槽位對應哪條譜線，不需要取得設備的設定檔。設備剛啟動、還沒有任何光譜時就讀得到。

| 位移 | 項目 | Ratio 1 | Ratio 2 | Ratio 3 | Ratio 4 |
|---|---|---|---|---|---|
| 16 | Slot enabled | `1022700116` = **1** | `1022700146` = **1** | `1022700176` = **1** | `1022700206` = **0** |
| 17 | Monitor mode | `1022700117` = **0**（比值） | `1022700147` = **0** | `1022700177` = **0** | `1022700207` = **1**（絕對強度） |
| 18 | Value semantics | `1022700118` = **1**（σ 分數）※ | `1022700148` = **1** ※ | `1022700178` = **0**（基準百分比） | `1022700208` = **1** |
| 19 | Extraction mode | `1022700119` = **2**（RawMean） | `1022700149` = **2** | `1022700179` = **0**（PeakHeight） | `1022700209` = **2** |
| 20 | Signal wavelength | `1022700120` = **337.1** | `1022700150` = **237.0** | `1022700180` = **357.7** | `1022700210` = **357.7** |
| 21 | Reference wavelength | `1022700121` = **750.4** | `1022700151` = **750.4** | `1022700181` = **750.4** | `1022700211` = **0** |
| 22 | Slot display name | `1022700122` = `N? 337 / Ar 750` ※※ | `1022700152` = `NO 237 / Ar 750` | `1022700182` = `N? 358 / Ar 750` ※※ | `1022700212` = `N? 358 absolute` ※※ |
| 23 | Signal species | `1022700123` = `N2` | `1022700153` = `NO` | `1022700183` = `N2` | `1022700213` = `N2` |
| 24 | Reference species | `1022700124` = `Ar` | `1022700154` = `Ar` | `1022700184` = `Ar` | `1022700214` = `""` |
| 25 | Ratio key | `1022700125` = `R_N2Ar` | `1022700155` = `R_NOAr` | `1022700185` = `R_N2357Ar` | `1022700215` = `R_N2357Abs` |

說明：

- **※ 位移 18**：分子為 RawMean 即為 σ 分數，比值模式也算。這是規格 v2.2 修正後的寫法，v2.1 原文與此不同，見 [§7](#7-規格與程式碼不一致之處v22v24-處理情形)。
- **※※ 位移 22** 是畫面上的顯示名稱（`DisplayName`，可隨時修改）。出廠名稱是 `N₂ 337 / Ar 750`，但 SECS 的 A 格式是 ASCII，下標 ₂ 送出時變成 `?`——Host 收到的就是表中的樣子。要長期追蹤同一組比值請用**位移 25 的 Key**：它建立後永不改變，改名、重排都不變。
- **位移 20** 是**套用波長校正後**的實際取值。例如在 Wavelength Calibration 分頁對 N₂ 337.1 加 +0.10 nm，`1022700120` 讀到的就是 **337.2**。
- **絕對強度模式**（Ratio 4）不使用參考線：位移 21 = 0、位移 24 = 空字串，位移 07／09（參考線 SNR／強度）也固定為 0。
- **停用的槽位**（Ratio 4，位移 16 = 0）身分類 VID 照樣可以讀，即時量的狀態為 6（Disabled）。
- 自訂譜線的物種一律以 `u` 開頭（如 `uN2`），由此可分辨現場自訂譜線與內建譜線。

## 4. 即時量 SVID：以 Ratio 2 為例

位移 01～15 每幀更新。下表以 Ratio 2（NO 237 / Ar 750.4）為例，VID = `130 + 位移`。範例值是虛構的，用來說明怎麼解讀：

| 位移 | 項目 | SVID | 範例值 | 解讀 |
|---|---|---|---|---|
| 01 | Monitored value | `1022700131` | 0.0412 | 本幀 NO 237 ÷ Ar 750.4 的原始比值 |
| 02 | Smoothed value | `1022700132` | 0.0409 | EMA 平滑值，狀態機以此判定 |
| 03 | Percent / σ score | `1022700133` | 126.0 | 先讀 `1022700148`：= 1，所以這是 **σ 分數**，不是 126 %，代表比基準高約 1.3 個警告 σ |
| 04 | Slope | `1022700134` | 4.2 | 近兩分鐘斜率；位移 18 = 1，單位為 σ/min |
| 05 | Ratio state | `1022700135` | 1 | Warning |
| 06 | Signal SNR | `1022700136` | 0 | RawMean 讀值不帶雜訊估計，SNR 是「未知」而非「很高」；設備送 0。位移 19 = 2 時位移 06 沒有意義 |
| 07 | Reference SNR | `1022700137` | 48.5 | Ar 750.4 的訊噪比 |
| 08 | Signal intensity | `1022700138` | 3745 | NO 237 視窗平均強度（counts，含連續光基座） |
| 09 | Reference intensity | `1022700139` | 90 900 | Ar 750.4 峰高（counts） |
| 10 | Baseline mean | `1022700140` | 0.0398 | Golden Run 基準平均值 |
| 11 | Baseline sigma | `1022700141` | 0.00026 | Golden Run 基準標準差 |
| 12 | Warn threshold | `1022700142` | 0.0406 | 現行警告門檻（含依實測雜訊加寬），與位移 02 同單位 |
| 13 | Alarm threshold | `1022700143` | 0.0414 | 現行警報門檻 |
| 14 | Ratio leak rate | `1022700144` | 3.1E-3 | 只由本槽位推得的洩漏率 Qᵢ（mbar·L/s） |
| 15 | Used in fusion | `1022700145` | 1 | 本幀有納入 VID 001 的融合估計 |

沒有值時一律送 0（不送 NaN）。0 有沒有意義看位移 05／18／19：05 為 3（NoPlasma）或 6（Disabled）時 01～15 都沒有意義；05 = 5（NoBaseline）時 10～13 沒有意義；19 = 2 時 06 沒有意義；洩漏率估計未進行（VID 006 ≠ 1）時 14、15 都是 0。位移 15 = 0 時位移 14 仍可能是非 0 的值（有讀值但沒納入融合），不要當成有效洩漏率。

同一個項目在四個槽位的 SVID（以位移 03 為例）：

| 槽位 | 位移 03 SVID | 單位（看位移 18） |
|---|---|---|
| Ratio 1 | `1022700103` | σ 分數（`1022700118` = 1） |
| Ratio 2 | `1022700133` | σ 分數（`1022700148` = 1） |
| Ratio 3 | `1022700163` | 基準百分比（`1022700178` = 0） |
| Ratio 4 | `1022700193` | σ 分數（`1022700208` = 1），但本槽位停用 |

## 6. Host 端建議的讀法

1. **建立對照表：** 連線後，或收到 CEID `10227507`（槽位身分改變）時，讀每個槽位的位移 16～25，記下「槽位 → Key／訊號線／參考線／單位」。507 只在身分真的變了才送（調整順序、增刪比值、改譜線／監測方式／擷取方式／啟用／名稱／波長修正）；只改門檻不送。
2. **以位移 25 的 Key 追蹤比值，不要以槽位號。** 工程師在 Ratio Setup 調整順序（▲／▼）或刪除、新增比值後，同一個槽位號可能換成另一組比值；用 Key 對應，才不會把 A 比值的歷史接到 B 比值上。位移 22 只拿來顯示。
3. **追趨勢：** 平常用 S2F23 Trace 追各槽位的位移 03（`1022700103`、`1022700133`、`1022700163`…），不要用事件報告逐幀推送。
4. **先看單位再判讀：** 每次讀位移 03／04 之前先看位移 18。0 是基準百分比、1 是 σ 分數；兩者共用 100／120／150 的刻度（基準／警告／警報），但物理意義不同，不可混算。
5. **停判不等於正常：** 位移 05 為 3～8 的槽位都不納入複合警報，Host 不應把它們當成 Normal。
6. **洩漏率要看校正狀態：** 位移 14 只有在 VID 006（Calibration status）= 1 時才有意義。

## 7. 規格與程式碼不一致之處（v2.2／v2.4 處理情形）

以下三點是比對規格 v2.1 與設備端程式時發現的。前兩點已在規格 v2.2 修正，第三點在 v2.4 決定。

1. **位移 18 的判定條件——已修正。** v2.1 §1.4(d) 寫「原始平均 **+ 絕對強度模式**」才改用 σ 分數；程式碼的判定是 `RatioDefinition.ValueHasPedestal`——分子是 RawMean 就算，**比值模式也算**，因為除以參考線只會等比縮放連續光基座，不會消掉它。照 v2.1 字面，出廠的 Ratio 1、2 會被標成「百分比」，Host 會讀錯。v2.2 改為只看位移 19。
2. **位移 05 的狀態碼——已修正。** v2.1 只列 0～6；程式碼另外還有 `Observing`（7，TrendOnly／Guard 角色）與 `NotApplicable`（8，不屬於目前的製程類別）。v2.2 已增列，附加在尾端，0～6 不變。
3. **位移 22 填哪個名稱——已決定（v2.4）。** 規格 v2.1 範例填 `R_N2Ar`，那是 Key。程式碼中 Key 一旦設定就永不改變（改名後基準與校正才不會失效），新增比值時 Key 是隨機 GUID 片段；畫面上顯示的是 `DisplayName`（如 `N₂ 337 / Ar 750`）。v2.4 的決定：**位移 22 = `DisplayName`，原保留的位移 25 = Key**，兩者都送。

| 值 | 意義 | 是否納入複合警報 |
|---|---|---|
| 0 | Normal | 是 |
| 1 | Warning | 是 |
| 2 | Alarm（鎖存，需操作者確認） | 是 |
| 3 | NoPlasma（電漿未開／參考線過弱） | 否 |
| 4 | LowSignal（訊噪比不足，停判） | 否 |

**Extraction mode（位移 19）**

| 值 | 意義 |
|---|---|
| 0 | 峰高（Peak height）— 扣除兩側連續光內插背景，單位 counts |
