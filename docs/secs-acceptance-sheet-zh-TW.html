事前準備

約 5 分鐘

三項都要在同一次連線裡完成，全程開著 SECS 分頁的 Traffic 與 Host 端的收送記錄。

  • 以 Engineer 帳號登入 App
  • Host 已連上，SECS 分頁狀態燈為綠色 COMMUNICATING
  • SECS 分頁勾選 Report alarms、Report events、Report test / replay data too，按 Save & apply 最後一項僅供本次測試，收尾時要關回去
  • 記下分頁中段的 Traffic log: 路徑，填進上方欄位
  • 備妥一段含洩漏事件的全譜錄檔 CSV 例：C:\DualOES\202608\14\P_OES1_0814220358.csv

Replay 分頁到引擎、三個 CEID

§13.4-1

驗的是「按鈕真的會呼叫到那些方法」。按鈕以下的整條路徑（錄檔 → 引擎 → S5F1／S6F11）已自動化。

  • Replay 分頁 → Choose CSV… 選錄檔，勾 Raise leak alarms during replay
  • Connect（會落到 test mode）→ Start Host 收到 CEID 1cc27508
  • Play（可用 5× 加速），等洩漏出現 Host 收到 ALID 1cc27001 set
  • 洩漏升級 Host 收到 1cc27001 clear ＋ 1cc27002 set
  • Leak Monitor 分頁 → Acknowledge Host 收到 1cc27002 clear 與 CEID 1cc27502
  • Stop Host 收到 CEID 1cc27509
  • 確認本次產生的檔名帶 SIM 前綴 SIMP_OES1_*、SIMP_Ratio_* — 重放資料不得與量測混淆

反向驗證（§13.4-2 的現場那半）：取消 Report test / replay data too → Save & apply → 重播同一段。 不應再收到任何 S5F1／S6F11，但 Host 送 S1F3 仍讀得到值且 VID 016 = 1。

  • 重播期間確實沒有任何 S5F1／S6F11
  • S1F3 仍回得到值，VID 016 = 1

設備故障警報（拔插光譜儀）

§13.4-3

ALID 012 是轉態不是狀態——必須先連上、再拔掉才會觸發。開機時本來就沒連線，不會、也不該送警報。

  • 確認光譜儀已連線，且 DevicePanel 不是 Test Mode
  • 拔掉光譜儀 USB Host 收到 ALID 1cc27012 set
  • 插回並重新 Connect Host 收到 1cc27012 clear
